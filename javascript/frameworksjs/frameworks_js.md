# Frameworks JavaScript

Frameworks e bibliotecas JavaScript são ferramentas criadas para acelerar o desenvolvimento, padronizar arquiteturas e facilitar a criação de interfaces ricas (SPAs) e sistemas complexos.

## Principais Tecnologias do Ecossistema

1. **React**:
   - Desenvolvido pela Meta.
   - Focado na construção de interfaces com componentes reutilizáveis e Virtual DOM.
   - Utiliza JSX e ecossistema com Hooks (`useState`, `useEffect`).

2. **Vue.js**:
   - Framework progressivo, fácil integração e curva de aprendizado suave.
   - Utiliza arquivos de componente único (SFC - `.vue`) e reatividade bidirecional intuitiva.

3. **Angular**:
   - Mantido pelo Google.
   - Framework completo (baterias inclusas) baseado em TypeScript, com injeção de dependências e roteamento integrado.

4. **Node.js**:
   - Ambiente de execução JavaScript no backend (server-side), permitindo usar a mesma linguagem no cliente e servidor.
