🪟 Janela Modal

Clique no botão abaixo para abrir uma janela modal. Você pode fechá-la clicando no "X", no botão "Cancelar", fora do modal ou pressionando a tecla Esc.

🎉

Modal Aberto com Sucesso!

Este é um exemplo de janela modal (também chamada de dialog). Modais são usados para exibir informações importantes, confirmações, formulários ou avisos ao usuário.

Este modal pode ser fechado de 4 formas diferentes:

  • 🖱️ Clicando no botão × (fechar)
  • 🖱️ Clicando no botão Cancelar
  • 🖱️ Clicando fora do modal (no overlay escuro)
  • ⌨️ Pressionando a tecla Escape (Esc)

📖 Conceitos aplicados neste exemplo:

  • classList.add() e classList.remove() para alternar visibilidade
  • addEventListener("click") para detectar cliques
  • addEventListener("keydown") para detectar teclas
  • event.target para saber qual elemento foi clicado
  • event.stopPropagation() para impedir propagação de eventos
  • Transições CSS com opacity e transform
