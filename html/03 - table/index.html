2. Demonstração de colspan e rowspan

💡 Conceito: colspan="N" faz uma célula ocupar N colunas (mescla horizontal). rowspan="N" faz uma célula ocupar N linhas (mescla vertical). Ao usar rowspan, a(s) linha(s) abaixo deve(m) ter uma célula a menos naquela posição.

3. Exemplo Avançado — colspan e rowspan combinados

💡 Conceito: É possível combinar colspan e rowspan na mesma tabela (e até na mesma célula) para criar estruturas complexas. A chave é contar corretamente quantas células cada linha precisa ter, descontando as ocupadas por merges.

📝 Resumo — Tags e Atributos de Tabela

Referência Rápida — Elementos de Tabela HTML5
Tag / Atributo Descrição Exemplo
<table> Define a tabela <table>...</table>
<caption> Título/legenda da tabela <caption>Notas 2024</caption>
<thead> Agrupa linhas de cabeçalho Contém <tr> com <th>
<tbody> Agrupa linhas de dados Contém <tr> com <td>
<tfoot> Agrupa linhas de resumo/totais Média, total, etc.
<tr> Define uma linha (table row) <tr><td>...</td></tr>
<th> Célula de cabeçalho (negrito) <th scope="col">Nome</th>
<td> Célula de dados <td>Maria</td>
colspan="N" Célula ocupa N colunas <td colspan="3">...</td>
rowspan="N" Célula ocupa N linhas <td rowspan="2">...</td>
scope Indica direção do cabeçalho "col", "row", "colgroup", "rowgroup"
